# Emberfall

A classic-style online RPG. This page holds the game itself, for Windows and Mac.

## Windows

1. Download **[Emberfall-Setup.exe](https://github.com/tysonPSF/emberfall-client/releases/download/client/Emberfall-Setup.exe)** (about 600 MB).
2. Run it. Windows will say **"Windows protected your PC"** the first time, because the game isn't signed by Microsoft. Click **More info**, then **Run anyway**.
3. Click through the installer. Emberfall goes on your desktop and in the Start menu.

## Mac

1. Download **[Emberfall-mac.zip](https://github.com/tysonPSF/emberfall-client/releases/download/client/Emberfall-mac.zip)** and open it.
2. Drag **Emberfall** into your Applications folder.
3. Open it. The first time, macOS won't open it, because the game isn't signed by Apple. Go to **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to Emberfall. After that it opens normally.

## Playing

Start Emberfall, choose **Play Online**, and make an account. The server is already filled in.

## Updates

Emberfall keeps itself up to date. When there's a new version, the title screen downloads it and restarts the game. Now and then a bigger change needs the installer again, and the game will tell you and link it here.

Everything is on the [releases page](https://github.com/tysonPSF/emberfall-client/releases/latest).
